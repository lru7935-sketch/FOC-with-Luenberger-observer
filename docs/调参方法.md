# 调参方法（本项目的实际推导过程）

不是试出来的参数。每一步都能算，也都能测。

---

## 一、电流环 PI

### 对象

```
G(s) = 1 / (R + sL)        R = 2.55 Ω, L = 0.9 mH
```

### 第一步：零极点对消定比值

PI 写成 `C(s) = Kp + Ki/s = Kp·(s + Ki/Kp)/s`，让零点对上对象极点：

```
Ki / Kp = R / L
```

消完之后开环变成 `L(s) = Kp/(sL)`，**R 从传函里消失**。

> 实践中故意把零点放在对象的 1.5 倍处（`Ki/Kp = 1.5·R/L`），
> 在穿越频率附近多送一点相位超前，稳定性更好。

### 第二步：穿越频率定增益

```
ωc = Kp / L        →   Kp = ωc·L
                       Ki = ωc·R
```

### 第三步：ωc 由相位裕度反推

环里有个固有延时 `Td`：ADC 在周期末采样 → 下一拍更新比较值 → PWM 零阶保持。
等效为 **1.5 个控制周期**（1 拍延时 + 半拍零保持）。

纯延时贡献的相位损失：

```
Δφ = (180°/π)·ωc·Td
PM = 90° − Δφ                 （积分器本身 −90°）
```

令 PM = 60°：

```
(180°/π)·ωc·Td = 30°   →   ωc·Td = π/6

ωc = π / (6·Td)
```

代入 `Td = 1.5/21250 = 70.6 µs`：

```
ωc = 7418 rad/s = 1181 Hz
Kp = 0.9e-3 × 7418 = 6.68
Ki = 2.55   × 7418 = 18916
```

> 常见错误：`Td` 只算 1 个控制周期，忘掉零阶保持的半个周期 →
> 算出来的 ωc 偏大 1.5 倍 → 相位裕度只有 45° 左右。

### 验证

给电流阶跃，看上升时间：

```
tr(10~90%) ≈ 2.2/ωc
超调 ≈ 5~10%（PM=60° 时）
```

实测偏慢 → Kp 小了或 Td 估小了；振荡 → Kp 大了。

## 二、PLL（速度/角度锁相环）

PLL 的对象不是 R/L，没法对消 —— 直接按二阶标准型指定。

### 结构

```
err(≈Δθ) → PI → ω → 1/s → θ̂ → 反馈
开环 L(s) = (Kp·s + Ki)/s²
闭环     = (Kp·s + Ki)/(s² + Kp·s + Ki)
```

对比 `s² + 2ζωn·s + ωn²`：

```
ωn = √Ki
ζ  = Kp / (2·√Ki)
```

**Ki 定带宽、Kp 定阻尼**（和电流环正好反过来）。

### 选值

- `ωn`：必须比速度环快 5~10 倍、比电流环慢 10 倍以上 → 30~60 Hz
- `ζ`：0.8~1.0（角度超调 = 转矩冲击，宁可过阻尼）

本项目：`ωn = 371 rad/s (59 Hz)`，`ζ = 0.95` → `Ki = 137641`，`Kp = 705`。

### 关键设计：误差归一化

```c
err = (Eα·sinθ − Eβ·cosθ) / |E|
```

不归一化的话 `err ∝ |E| ∝ 转速`，环路增益会随转速变化几十倍 ✗。
归一化后 err 是纯角度量（sin Δθ），**一组参数覆盖全速域** ✓

代价：低速时 `|E|` 很小时归一化失效，err 被放大 → 积分跑飞。
所以必须有反电势门限，否则会看到"电机静止但观测器报 800 rps"。

## 三、观测器带宽 ω0（龙伯格）

```c
K1 = 2·ω0 − R/L
K2 = −L·ω0²          /* 双极点在 −ω0 */
```

反电势估计对真值的响应近似一阶低通：

```
Ê/E ≈ ω0/(s + ω0)     →   角度滞后 = atan(ωe/ω0)
```

### 两个边界

**下界**（高速角度滞后）：

```
20 rps → ωe = 880 rad/s
ω0 = 2000 → 滞后 23.8°   ✗
ω0 = 4000 → 滞后 12.4°   ✓
```

判据：最大转速下滞后 ≤ 10~15° → `ω0 ≥ 4~6 × ωe_max`

**上界**（低速噪声）：

```
电流噪声 0.01 A × R = 0.026 V
1 rps 时 |E| = 0.22 V → 角度抖动 ≈ 7°
```

`ω0` 越高，进入估计的噪声带宽越宽，低速抖动越大。

### 推荐：按转速调度

```c
const float w0 = fminf(fmaxf(4.0f * fabsf(Omega_E), 1500.0f), 5000.0f);
```

让全速域滞后恒定在 ~14°，低速保留最小带宽。

**注意离散化**：欧拉离散要求 `ω0·Ts ≪ 1`。`ω0 = 8000`、`Ts = 47 µs` 时
`ω0·Ts = 0.38` 已经偏大，极点位置会和设计值偏离。

## 四、速度环

对象是 `Kt/(J·s + B)`，形式上也能对消，但实际很少这么做：

1. **B/J 太低**（本电机约 1 Hz），远低于穿越频率，对消买不到相位
2. **J、B 不准**（负载变了 J 就变）
3. **齿槽转矩、库仑摩擦是非线性的**，对消只对线性部分有效
4. 速度环的真实相位限制来自 PLL（二阶）+ 电流环延时，不是机械极点

所以速度环按"比 PLL 慢 5 倍"给经验值，再看阶跃响应调。

## 五、测量方法（比算更重要）

### ISR 耗时

用 1 MHz 自由运行的定时器打点：

```c
if (Foc_EN) {
    const uint32_t t0 = TIM2->CNT;
    Foc();
    Isr_Us = TIM2->CNT - t0;
}
```

本项目实测：18.4 µs（最大 21 µs）。分项：

| 段 | 耗时 |
|---|---|
| `sinf + cosf` | 4.1 µs |
| SVPWM（6 次 `fmaxf/fminf`）| 4.5 µs |
| `Get_Ia/Ib/Ic`（9 次函数调用）| 2.2 µs |
| Clark + Lbg（含 7 次运行期除法）| 2.0 µs |
| PID×2 + Arc_Park | 2.0 µs |
| PLL | 1.5 µs |
| 其余 | 1.8 µs |

### 观测器角度误差

装一个 AS5600（12 bit 磁编，I2C）→ 把编码器电气角和观测器角度同时上传 →
统计两者差值的均值与标准差，随转速扫描。

**没有真值参考时，你会一直在"是不是角度错了"里打转。**

### 电流环阶跃

给 `Iq` 阶跃，看上升时间是否符合 `2.2/ωc`。

## 六、几个反直觉但重要的结论

1. **`fmaxf/fminf` 在 M4 上是库函数调用**，比三目运算符慢 20 倍。
   FOC 里每次都调 → 4.5 µs 就这样没了。
2. **`extern const float` 会阻止常量折叠**：`/PHASE_L/IN_LOOP_FRE` 是两次运行期除法。
   改成 `#define` + 预算倒数 → 省 2 µs。
3. **`sinf()` 一次约 180 周期**（@170 MHz），两次就 2 µs。
   CORDIC 或 `sqrtf(1-sin²)` + 象限判断都能替代。
4. **SVPWM 的电压上限和采样窗口是两回事**：`√3/2·Vbus` 是电压能力，
   但下管导通窗口会在更早的地方消失 → 电压要留 10~15% 余量。
5. **纹波不影响控制精度**：采样点固定在纹波谷值 → 是个恒定偏置 → PI 和速度环都会吸收掉。
6. **死区补偿的阈值不要设在电流量级上**：`I0=0.5A, I1=0.8A` 这种设置
   会让"半个工作区间"处在补偿启停边界上，产生和电流相关的怪现象。
